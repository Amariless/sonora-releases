# Sonora — descargas

Instaladores de **Sonora**, un reproductor de música de escritorio para Windows y Linux.

Descargá la última versión:

| Sistema | Archivo |
| --- | --- |
| Windows | [`Sonora-Windows-Setup.exe`](../../releases/latest/download/Sonora-Windows-Setup.exe) |
| Linux (cualquier distro) | [`Sonora-Linux-x86_64.AppImage`](../../releases/latest/download/Sonora-Linux-x86_64.AppImage) — dale permiso de ejecución (`chmod +x`) y abrilo |
| Debian / Ubuntu | [`Sonora-Linux-amd64.deb`](../../releases/latest/download/Sonora-Linux-amd64.deb) |

Todas las versiones anteriores están en [Releases](../../releases).

La app se actualiza sola desde acá: **Configuración → Actualizaciones → Buscar actualizaciones**.
Las actualizaciones están firmadas; la app rechaza cualquier archivo que no sea el original.

Este repositorio solo contiene los instaladores publicados; el código fuente es privado.
